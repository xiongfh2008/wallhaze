## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Media & asset licensing

The open-source license of this repository covers the **code**. It does not
automatically extend to the wallpaper previews and gallery images: every
media asset carries its own usage rights.

- Per-asset provenance, license type and review status are recorded in
  `apps/web/data/media-rights.json` (generated by
  `apps/web/scripts/media/build-rights-registry.mjs`) and summarised in
  `docs/codex/MEDIA-ASSET-INVENTORY.md`.
- Assets marked `wikimedia-cc0` are CC0 1.0 and may be reused freely.
- Assets marked `project-generated-ai` are display-only project assets
  (download disabled); they may not be redistributed or used commercially
  without the project's permission.
- Pending or restricted material is never served from `public/`. Original
  renders and quarantined derivatives live in the local-only, git-ignored
  `apps/web/private-media/` workspace and are not part of this repository.

Adding a code LICENSE file (or relaxing any media restriction) is an explicit
owner decision and is intentionally not part of this scaffold README.
